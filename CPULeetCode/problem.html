The Hoff ISA

The Hoff ISA is intended to run on the Hoff-16, a custom designed 16 bit CPU.

There are 16 instructions + 3 macros(commands that map to other instructions for easy use) you can run. All arithmetic and values are done with 16 bits.

There are also 16 registers with R0(constant 0), R1(constant 1), R13(stack pointer), R14(flags) and R15(program counter) being reserved for CPU operations leaving R2 - 12 open for your program.

Registers are meant to hold temporary data that can be manipulated by an instruction, and can interact with memory by loading or storing values to RAM.

You have 65536 addressable locations in RAM where each location contains 16 bits of information. The program is stored in RAM starting at memory address 0x0000 so it is recommended to store any variables around 0x2000, the stack begins at 0xDDDD and works downward

Each command will follow this structure:

COMMAND Par1 ... parN;

You can also mark loop points by writing

loop name;

loop points are places where you're program can jump to with the jump command, this is useful for loops, branching, and more. It does not matter if a loop point is after or before the jump.

Here are the commands:

LOAD destinationRegister ramAddr; --> loads whatever value is stored at the provided ram address into the provided register.

LI destinationRegister literal; --> loads the provided literal to the provided register.

STORE addressRegister valueRegister; --> stores the value in the register to ram at the address in the register.

ADD destinationRegister valueARegister valueBRegister; --> adds the values in register A and B and stores the result in the destination register.

SUB destinationRegister valueARegister valueBRegister; --> subtracts the values in register A and B and stores the result in the destination register.

AND destinationRegister valueARegister valueBRegister; --> binary ands the values in register A and B and stores the result in the destination register.

XOR destinationRegister valueARegister valueBRegister; --> binary xors the values in register A and B and stores the result in the destination register.

OR destinationRegister valueARegister valueBRegister; --> binary ors the values in register A and B and stores the result in the destination register.

PUSH valueRegister; --> pushes the value in the register to the stack;

POP destinationRegister; --> pops the value from the top of the stack and stores it in the register;

JMP type check loopPoint; jumps to the specified loop point if the condition is met. The condition is based on the flags register, each type checks if one of the flags is equal to the check parameter(0 or 1), so the flags are E(equal) N(negative) and U(unconditional jump), E will be 1 if the last comparison was equal, N will be 1 if the last comparison was negative, and if the type is U the jump will always be true. So if the stored value for the flag equals the check then the jump is true and code execution will move to the jump point.

CMP registerA registerB; --> sets the flag register based on registerA - registerB as described above.

SHL destinationRegister valueARegister valueBRegister; --> Binary shifts to the left the value in the register A by the value in register B and stores the result in the destination register;

SHR destinationRegister valueARegister valueBRegister; --> Binary shifts to the right the value in the register A by the value in register B and stores the result in the destination register;

MULT destinationRegister valueARegister valueBRegister; --> multiplies the values in register A and B and stores the result in the destination register.

DIV destinationRegister valueARegister valueBRegister; --> divides the values in register A and B and stores the result in the destination register.


Macros:

INC register; --> increments the value in the register(maps to ADD register R1 register)

DEC register; --> decrements the value in the register(maps to SUB register R1 register)

MOV destinationRegister otherRegister; --> sets the value of the destinationRegister to the value of the otherRegister(maps to ADD destinationRegister otherRegister R0;)


Example lines:

LOAD R3 65525; --> loads whatever is at ram address 65525 into register 3

JMP E 0 main; --> jumps to the loop point named main if the last comparision was not equal

ADD R2 R2 R3; --> stores into R2 R2 + R3;
