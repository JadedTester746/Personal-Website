Making your own CPU and ISA is not an easy task. It requires a ton of logic, design tradeoffs, and knowledge of low level computer architecture. But I feel that after putting in the work you leave with a stronger sense of how computers and code works at the lowest levels of abstraction which makes you a stronger programmer.

The CPU I designed, the Hoff-16 is a 16 bit cpu meaning that all arithmetic and vararibles stored are 16 bits. This is also called the word size. There are 16 supported instructions described in the ISA, 16 registers with 5 reserved for CPU operations, and 65536 addressable RAM locations each storing a 16 bit word

The code editors in the following problems are only emulating the ISA, the actual CPU can be downloaded and ran on logisim along with a link to assemble your code into binary

Solving a couple of these problems will give you an idea of how assembly code works and what your computer code is actually doing on the CPU

Essentially all modern programming languages are compiled or interpred to assembly and machine code, much like the instructions you are going to write.
